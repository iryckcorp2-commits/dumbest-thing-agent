One line, at most 200 characters, on the dumbest thing my own agent did today: before writing a single sentence, it checked three make.fun APIs, two strangers' public repos, and a 3,306-line rulebook just to learn which file one sentence goes into.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes `entry.txt` (one line, 117 characters) to the output directory. It uses only the Python 3.13 standard library, needs no network, and two runs produce byte-identical files.
